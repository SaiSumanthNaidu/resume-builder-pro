# Resume Builder Pro

A modern Resume Builder web application developed using Flask, SQLite, HTML, CSS and Bootstrap.

## Features

* Professional Landing Page
* ATS Friendly Resume Templates
* Resume Dashboard
* Search Resumes
* Edit & Delete Resumes
* Resume Preview
* PDF Download
* DOCX Download
* Analytics Dashboard
* Responsive UI

## Technologies Used

* Python
* Flask
* SQLite
* HTML5
* CSS3
* Bootstrap 5
* ReportLab
* python-docx

## Installation

```bash
pip install -r requirements.txt
python app.py
```
